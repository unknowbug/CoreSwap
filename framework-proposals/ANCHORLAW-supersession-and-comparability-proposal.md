# 提案：证据/结论的持续性与取代链——协议级补充

- 提案对象：Anchorlaw Protocol v0.17 → v0.18 候选
- 提案人：CoreSwap multiworld-port session（2026-09-01）
- 状态：draft（待维护 agent 评估）
- 实证来源：CoreSwap M11/M14/M16（跨 session 假设污染、探针域自洽掩盖存档层错误、部分验证口径误用）+ DSH `packages/compaction/*` 事件溯源设计借鉴

## 1. 问题陈述（协议层视角）

三个在实战中暴露、现有条款未覆盖的缺口：

1. **§5.3 Staleness 只覆盖 anchor，不覆盖结论/交接**：anchor 有 staleness 检测（§5.3/§5.4 健康状态），但**交接文档、台账「机制方向」、未验证假设**这类更上游的结论没有任何 staleness 机制——CoreSwap M14 一轮绕路的直接根因就是下轮把上轮的「机制方向（candidate 未验证）」当公理续推。
2. **结论被推翻后缺乏取代语义**：M16 推翻 M14 的方向性结论，但协议没有「取代链」表达——现状靠手写「【已结案/作废】标注」，无法机械回答「当前有效结论是什么」；§11 claim audit 也无法沿取代链追溯一个结论的演化史。
3. **验证分层（§9.1）的口径漂移无约束**：CoreSwap 同一对象出现两个百分数（探针口径 96.06% vs 存档写入口径 82.16%），载体/覆盖面不同但都叫"对齐率"——跨口径比较差点误判为"回归"。协议要求声明降级模式（§9.5），但未要求声明**对比口径本身**（载体、覆盖面、与既有口径的可比性）。

## 2. 具体条款提案

### 2.1 新增 §5.7 Conclusion Supersession（结论取代链）

- 任何 candidate 及以上结论被后续证据推翻/精化时，MUST 以**取代记录**表达：原结论标注 `superseded_by: <新结论id>`，新结论标注 `supersedes: <旧结论id>` + 一行推翻理由。**原结论正文不得删除或改写**（证据链完整性，对齐 First Law 的可审计精神）。
- 取代链 MUST 可机械回答：「关于 X 当前有效结论是什么、演化史是什么」。
- 与 §11 的关系：claim audit 沿取代链审计到链头（当前有效结论），而非孤立 claim。
- 与 §5.3 的关系：staleness 检测（时间/来源失效）是取代的触发器之一，取代记录是 staleness 的落地动作。

### 2.2 新增 §9.7 Verification Comparability Statement（对比口径声明，v0.7 §9.6 的姊妹条）

- Partial/Degraded 降级声明（§9.5）之外，凡输出量化对齐/一致性指标，MUST 同时声明**对比口径三要素**：① 载体（两侧各自在什么表示域/什么产物层对比）② 覆盖面（样本范围、单点/批量、含哪些生成阶段）③ 与既有历史口径的可比性（可延续/不可延续，不可延续 MUST 一行说明差异）。
- 反例实证：探针域自洽的 96.06% 与存档级 82.16% 被直接对比，差点误读为"回归 14pp"——实际两者载体不同（raw id 域自洽 vs 跨域写入解码后逐位），无任何可比性。

### 2.3 新增 §16.2 Host Handover Validation（宿主交接验证，挂 Host Integration Contract）

- 宿主跨 session 交接时，交接文档中的「机制方向/待查假设」类条目（区别于已过 judge 的定论）MUST 标注验证状态；继承方开工前 MUST 对拟继承的方向性结论执行一次**廉价独立验证**（≤1 轮成本），方可作为推理前提。
- 理由：交接是宿主契约的一部分（§16.1），但现有 checklist 只管"交付了什么"，不管"交付物里哪些是公理哪些是假设"。反例实证：M14 方向错误 + M11 三犯的共同根因均为「假设跨 session 升格为公理」。

### 2.4 建议不新增而复用既有的部分（明确边界，防条款膨胀）

- 证据持久性（原始数据不可变）→ 已由 §5.5 trace/memory source 规则 + noise card 机制覆盖，本提案不重复定义。
- 压实/合并的执行流程（谁执行、subagent 与否）→ 属宿主/RE-Framework 层职责（§16 hosts MAY），协议只约束取代链与口径声明的**语义**，不约束流程。

## 3. 迁移与验收

- 迁移：取代链对存量结论惰性补齐（新结论 MUST）；口径声明自 v0.18 起生效，存量历史口径在下次引用时补一行可比性声明。
- 验收判据：① 任一结论可机械回答"当前有效版本 + 演化史"；② 一次推翻操作 = 1 条取代记录 + 0 次原文改写；③ 抽查任意量化结论，三要素齐全且历史口径可比性显式。
