## 发现 #159: 追加预登记判据的「事后逐臂展开」合法性三条件——两臂分裂实测后逐臂读法不越界的操作化边界（260917-01）

- **发现时间/发现者/置信度/module**：260917-01；worker(.b1b4) 判读自认 + judge §J2 复核通过（升格为条件 C2a）+ knowledge subagent 草稿；candidate（单轮实锤，待复用升级）；workflow-patterns / 判据预登记设计（#112 读法写死 + #154 灰区归属家族；#157 判据 3 的操作化独立条）。
- **来源定位**：`.investigations/g3-drift-basis-260917-01/`（criteria-260917-01.md C-B4 条 + candidates/.b1b4-convergence-verdict-draft.md §2 + judge-review-260917-01.md §J2/C2a）；实例 = C-B4 run3 两臂分裂（legacy G17c-L3 200 changed 9.88% 命中 M-b / domain G17c-D3 2 changed 0.10% 命中 M-a）。
- **观察（现象）**：C-B4 判据按「两臂共同行为」预登记（M-a 收敛瞬态 / M-b 持久不稳定两分支 + 灰区归属条款），未预登记「两臂各命不同分支」的分裂情形；实测恰为分裂。worker 逐臂自然展开后自我标注「判据文字未预登记分裂分支，本读法为事后裁量，建议 judge 复核是否越出预登记范围」；judge 审查确认展开**未越出实质边界**（未新增阈值、未改写分支语义、灰区条款未被绕过、两臂各自独立过自证硬门不构成挑臂），并将「引用须携带裁量声明」升格为强制条件 C2a。分裂本身是本探针最大的信息增量——处置难点不在读数，在「未预登记情形的读法合法性」。
- **判据（可复用，三条件齐备才合法）**：实测两臂分裂命中不同分支时的逐臂展开，合法当且仅当：
  1. **不新增阈值、不改分支语义**——只把既有分支逐臂套用；灰区条款照旧生效、不被绕过（本例 legacy 基底交集 48.3% 落灰区段 20-60%，被「或」联结吸收、不单独结论——处理正确）；
  2. **显式标注「事后裁量」并 worker/judge 双复核**——worker 展开时自我标注交 judge；judge 裁定「保守自然展开，非挑臂」后方可用作判据读法；
  3. **正式引用文本内嵌限定行**——任何后续引用（含 §15.4 取代记录）MUST 携带「判据未预登记分裂分支，逐臂读法为事后裁量（worker/judge 均已复核）」一行（#112 预登记纪律 + #154 灰区归属家族；来源 = 260917-01 C-B4），使读者在引用点即见边界。
  静默展开（不标注、不复核）= 判据污染（#150 同族）；回改判据原文 = 同样违规（判据定稿后不可回改）。
- **教训**：预登记判据的分支枚举天然锚定「预期行为形态」，实测形态分裂无法在预登记时穷举（与 #154「实数轴覆盖」并列的第二类盲区：**分支对象维度**的覆盖缺口）。正确姿势 = 三条件展开，既不弃读也不越权。
- **与 #157 判据 3 的分工**：#157 判据 3 立「分裂逐臂展开 MUST 带事后裁量声明」这一行；本条把它操作化为「怎么展开才算合法」的三条件完整判据，两处互相引用不重复。
- **家族索引**：#112（读法预登记写死）/ #154（灰区归属——本条补「分支对象覆盖」维）/ #157 判据 3（声明行 MUST 出处）/ #150（预登记与采集同稿）。
