## 1. 机制候选分解（互斥候选 + 判别探针）

### 结构性前置事实（静态一手，候选分解的地基）

- **F1**：Rust 内核 `light_compute` 输入 = blocks9（3×3 邻域方块 raw id），**不读任何 stored light**（mod.rs:182-192 签名；`light_compute_inner` 五阶段全在 scratch 局部缓冲上）。内核是 blocks9 的纯函数——**per-chunk 路径在 Rust 侧不存在「邻 chunk stored 光照循环依赖」的输入通道**。
- **F2**：legacy 接管在收集失败（邻 chunk 缺失 / 状态 < FEATURES / 高度不符 / rc≠0 / native throw）时**不 cancel → 走 vanilla light()**（mixin :637-657, :677-683）。vanilla 路径是增量 BFS，**依赖 LightStorage 中邻 chunk stored 光照**——这是混合系统里唯一携带跨 chunk / 跨 run 光照反馈的通道。
- **F3**：light() 被调用的前提与时点不由 mixin 控制；重载时 chunk 是否重走 light() 还是信 stored light，属 vanilla TACS 票据时序（本 worker 未一手核对，标 @anchor.idk）。
- **F4**：纯 vanilla 臂同协议 drift 仅 ~0.8% → 漂移主体是接管臂特有，非 vanilla 固有噪声地板。噪声地板 = 7.3%（stable 组跨臂终态不等率）。

### 候选 M-a：run1 预生成早期 stale 计算无失效 → run2 单次纠正（收敛瞬态）

- **机制**：run1 生成期，chunk C 的 light() 在 3×3 邻居刚到 FEATURES 时触发；FEATURES 邻居的方块随后仍会被自身 feature 阶段改写 → C 的 blocks9 是「早期形态」→ 光照 stale 且 setLightOn+摘票后无失效机制（mixin 全文无任何失效/重算钩子，F2 之外零补偿路径）。run2 重载时世界已在盘、邻居最终形态 → blocks9 变 → 重算纠正。
- **支持**：run1→run2 大改（120/2025）；kernel 纯函数 + 重载输入变全 → 一次修正语义自洽；domain 臂一次重载即收敛（run3=2）与「一次 warm-up 修正」预期完全一致。
- **反对**：**legacy run3 仍 200 changed（9.88%，基底交集仅 48.3%）**——若重载输入已是最终形态，run2 与 run3 的 blocks9 相同、输出应逐位相同 → run3 应 ≈0。M-a 单独**不成立**。
- **调和子候选 M-a'**：重载期 legacy 仍有**时变性输入**，使 run2/run3 各自的 blocks9 ≠ 盘上最终形态。两个具体通道（互不排斥）：
  - **M-a'-α（fallback 混合）**：重载加载序下部分 chunk 的邻 chunk 尚未到 FEATURES → 收集失败 → vanilla 回退（F2）。vanilla 回退块的光照 = 增量 BFS，依赖当时 LightStorage 里邻块 stored 光照（即上一 run 的混合输出）→ **跨 run 反馈环**；哪些块回退随加载时序逐 run 变 → 逐 run 漂移、无不动点。这把「候选②循环依赖」限定到它真实存在的唯一位置：**vanilla 回退子路径**，而非 Rust 内核（F1 排除后者）。
  - **M-a'-β（空节瞬态读）**：邻 chunk 已达状态门但 section 数据尚未反序列化/瞬态空 → `sec.isEmpty()` 读真 → 静默填 AIR（mixin :211-216，**无打点、不回退**）→ blocks9 错、输出欠亮。逐 run 加载时序不同 → 错值子集不同 → 逐 run 漂移。此通道**完全静默**，比 α 更隐蔽。
- **判别探针（廉价，按性价比排序）**：
  1. **P-α**：翻 G17/G17b 日志统计 `[LightRust] fallback vanilla xN` 计数与逐条 chunk 坐标，与各 run changed 集做交集率。fallback 集 ∩ changed 集显著 → α 主嫌疑实锤；fallback≈0 → α 排除，转 β。
  2. **P-β**：临时诊断（env 门控，chunk 级）：collect 时命中 `isEmpty()==true` 的邻居节计数 + chunk 坐标打点，重载 run 采集一轮，与 changed 集对拍。（或：同 chunk 提交时与 settle 后双采集 blocks9 hash 对拍，#48 惯例。）
  3. **P-path（归因面）**：每 chunk 打「本 run 走 rust / fallback-vanilla / 未触发 light()」三态归因图，两 run 差分——一次采集同时分辨 α/β 与「信 stored 未重算」（F3 idk）三种时变来源。
- **预测**：若 α/β 任一实锤 → 修复（失败重试/延迟计算/空节守卫）后 legacy 也应 run3≈0 收敛；若 P-path 显示「信 stored 未重算」子集逐 run 变 → 第三通道（票据/时序面）立案。

### 候选 M-b：per-chunk 邻域 stored 值循环依赖 → 极限环（原候选②）

- **机制（原表述）**：legacy 每次重载都重算且输出依赖邻 chunk stored light → 不动点不存在 → 极限环。
- **反对（结构性，强）**：F1——Rust 内核签名无 stored light 输入；per-chunk 输出互不依赖（各 chunk 独立纯函数），**Rust 路径内部不可能构成循环**。kernel 级 `light_compute_domain_bitwise_equivalence` 测试（mod.rs:650）与纯函数 golden 门（.b1 §5.2）同证。
- **支持（限定形态）**：仅当与 M-a'-α 复合——循环依赖存在于 **vanilla 回退子路径**（vanilla 增量 BFS 天然依赖 stored 光照），混合系统的「Rust 块定值 + vanilla 块逐 run 变」可以表现为永不收敛，且与 run3 继续漂、交集 48.3%（部分稳定部分漂）的形态吻合。
- **判别探针**：同 P-α（fallback 计数是本候选的生死判据）。若 fallback 恒 0，M-b 整体证伪。
- **预测**：若 α 实锤且不修，run4 应继续漂（changed 非零、集合部分重叠）——可作 C-B4 延伸（run4 探针）验证。

### 候选 M-c：spawn ticket 区特殊加载时序 × 接管交互

- **机制**：漂移基底 120 chunk **100%** 聚集 spawn 邻域箱（x[15,36]×z[-24,-4]，区域边缘环 0%）——这是 #80（spawn 预生成时序：SERVER_STARTED 前 spawn 区块已走完一条与普通 forceload 不同的生成/加载路径）的空间签名。spawn 区在每次 boot（含重载）都经 spawn ticket 特殊时序再入 light()，其邻居就绪度/回退率/空节概率与普通区结构性不同 → 漂移被圈定在 spawn 箱。
- **支持**：空间分布 100% 聚集 + 边缘环 0%（生成区 45×45 内非 spawn 箱完全不动）；#80 家族先例（spawn 时序特异）；纯 vanilla 臂仅 0.8% 说明该时序本身不漂，漂需要接管交互。
- **反对/边界**：M-c 单独**不解释逐 run 变化**——spawn 时序若逐 run 确定性相同，输出应逐 run 相同。故 M-c 定位为**空间定位层**（解释"在哪漂"），逐 run 变异仍需 M-a'-α/β 之一作变异通道。两候选非真互斥：M-c ∘ M-a' 复合模型 = 「spawn 时序制造高时变输入密度区，α/β 提供逐 run 变异」。
- **判别探针**：P-path 三态归因图按空间叠合——fallback/空节命中是否也 100% 落在 spawn 箱 → 复合模型成立；时变命中散布全区而 changed 只在 spawn 箱 → 需第四通道（spawn 区 stored light 不落盘/重算策略差异，@anchor.idk 未核）。

### 候选间关系小结（供归因综合引用）

M-b 作为独立候选被 F1 结构性削弱（降至「仅 vanilla 回退子路径形态」并入 M-a'-α）；活树 = **M-a'（α/β 变异通道）× M-c（空间定位）**。裁决探针 P-α → P-β → P-path 依次廉价排除。

## 2. domain 域批一次收敛的机制解释

- **自洽性来源（结构性）**：`light_compute_domain`（mod.rs:308-338）对 9 中心各自以 5×5 帧的对应 3×3 子窗调**同一个** `light_compute_inner`——内核纯函数（F1），域内 9 中心输出两两独立、无 stored 依赖。因此**只要输入帧（blocks25 快照）相同，输出逐位确定**。run2/run3 重载时世界已在盘、b9 快照在提交线程取自已反序列化的最终方块（domain 预检要求 3×3 邻居全部到位，mixin :457-465），输入逐 run 恒定 → run2 后 run3 仅 2 changed（0.10%≈噪声地板）。
- **与 legacy 的差异面（为何 legacy 不收敛而 domain 收敛）**：
  1. **执行时点解耦**：域批任务投递 FJP、封板/宽限期使其普遍晚于生成链（.b1 §1.2b/§4.1「时机解耦」正是其设计目的）→ 快照时世界更接近最终形态，早期 stale 计算面小；
  2. **回退面结构不同**：domain 预检失败 → WG_DOMAIN_INLINE 计数后仍走 legacy/vanilla（mixin :694-697），但**任务期失败是 loud fail/降级重放计数**（st.DEGRADED），混合面小且可见；legacy 的 fallback（M-a'-α）与空节（β）静默且逐 run 变。收敛差异本身就是「时变输入通道主要在 legacy 侧」的旁证。
  3. 注意：domain run1→run2 仍有 164 changed（8.20%）——与 M-a 一致：run1 生成期的 stale 计算同样存在于域臂，只是**一次重载即修正干净**（域臂变异通道弱）。
- **可检验预测**：若对 legacy 修掉 α/β 通道（P-α/P-β 实锤后），legacy 也应一次重载收敛至 ≈噪声地板——此预测与 M-c 无冲突（spawn 箱只是时变密度高的区域，修通道后密度归零）。

## 3. CP-1（.b1 域批）去留决策输入（不拍板）

### 3.1 保留 .b1 的收益面

1. **收敛性（本轮新增、实测）**：domain 臂 run3 = 0.10%（≈噪声地板），是唯一被实测证明「round-trip 存在不动点」的光照形态。legacy 臂在 α/β 修复前无法给出同等承诺。G3 判据载体若要保留 run 级 drift 阈值，domain 路径是已知可行载体。
2. **A1 批收益未测（.b1 §4.2 预登记）**：JNI 往返 9→1、收集 81→25 的结构性收益与 phased 分解（fill vs BFS 占比）均待 A/B 实测——保留 .b1 才能收到这笔账；放弃则该设计案整体作废。
3. **时机形态解耦**（.b1 §4.1）：light 完成时刻与生成链解耦，是「时机形态主导」归因（260915-03 探针②）的构成性改动面。

### 3.2 G3 载体定性修正后 C-1 的重述建议（供归因综合/主会话措辞）

- 现行 C-1「drift <2.5% @ Done+20s」被本轮定性拆成两层：**run1→run2 段 = warm-up 修正瞬态（M-a，可经预热轮消化）** + **run2 以后段 = 时变输入通道残余漂移（M-a'-α/β，legacy 特有，域臂≈0）**。原 2.5% 阈值与「单轮即判」载体绑定，对 legacy 两层都不可达（run3 仍 9.88%），载体整体失效（对应 criteria C-B4 的 M-b 分支读法）。
- 重述方向（二选一，决策输入非决定）：
  - **R1（载体换轨）**：C-1 改为「run2→run3 后验 drift ≤ 噪声地板带」且在 domain 载体上判（预热轮后测），legacy 臂同判据仅作形态对照；
  - **R2（载体换型）**：按 #52 家族换确定性 dump 类载体（settle 后快照 vs 盘上参照），彻底脱离 Done+Ns 窗。
- 无论 R1/R2：**legacy 臂的 α/β 通道修复是其任何 drift 判据可达的前置**，否则 legacy 永久超阈。

### 3.3 各分支前置验证项

- **若保留 .b1（转主路径）**：
  1. 端到端 golden 逐位等价门在真实负载复证（kernel 级已有 mod.rs:650 测试；e2e 层 .b1 §5.2 三门未全跑）；
  2. A/B 同构建态自证硬门成对（#118：`[LIGHT-DOMAIN] task` + SEALED 正证据、WG_DOMAIN_INLINE/DEGRADED 负证据）——本轮域臂数据已过自证硬门，但须在 A/B 协议中固化；
  3. A1 P50/P90 + phased 分解同批采集（.b1 §4.2 判别性预登记：fill+JNI <30% 则 A1 收益主张撤回）；
  4. 宽限期敏感性扫一遍（C-B3 若执行可直接复用）。
- **若转 .b2/.b3（其他候选）**：前置 = 先关闭 G3 归因（P-α/P-β/P-path 探针链出结论），否则新形态仍在同一个未归因的时变输入面上打转（.b1 之外任何形态都不自动获得收敛性——收敛实证目前只属于 domain 形态）。
- **共同前置（与 CP-1 去留独立）**：legacy 静默空节读（β）即使 .b1 保留也应修——降级重放路径仍走 legacy（mixin :583），通道不修则降级面仍是漂移源。
