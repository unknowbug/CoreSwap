## §2 全覆盖驱动方案（-Pformdrivegrid=1）

### 2.1 waypoint 网格

- **覆盖域** = face bbox [14,−24]..[331,211]（318×236，前块 t8 口径，转引未复算）。
- **间距 20，含端点收敛**：x = 14+20k, k=0..16（末点 334 ≥ 331−10=321 ✓）；z = −24+20k, k=0..12（末点 216 ≥ 211−10=201 ✓）。**W = 17×13 = 221 个 waypoint**。
- **默认 = hold-all（不摘票）**：grid 模式只 addTicketWithLevel、**不 removeTicketWithLevel**（对 T8 走廊式摘票的显式偏离，理由：摘票→卸载竞态正是上臂 unlit 形态嫌疑机制，全覆盖判别臂必须消除它，否则「缺席随覆盖收缩」的读数被卸载竞态污染）。内存代价见 §6 R1。
- **行进序** = 蛇形 row-major（相邻 waypoint 空间连续，生成请求局部性最好；hold-all 下顺序不影响最终集，只影响生成峰值面）。
- **降级变体 D-Prune**（预算不可接受时启用，判读不变）：waypoint 集裁剪为「21×21 方块 ∩ face 集 ≠ ∅」者（离线由 face json 预算，不拍脑袋）；裁剪后 W、deadline、覆盖率门全部按实算值**先重登记再跑**。
- **降级变体 D-Lag**（内存不可承受时启用）：摘票但滞留 L=2 个 waypoint（≈30s+2×GRACE 余量）后才 remove；启用时必须在判据 json 声明 `ticket_release=lag2` 且 S2 覆盖率门收紧至 ≥0.90（§3.1 QG3）。

### 3.2 判别判据（核心，读法写死）

**记号**：N520 = 上臂 never-enter 集（520，历史 run 产物）；face_new = 新臂 snap lit 面；terminal(c, arm) = 该 chunk 在该臂分账终态（7 类，design-260920-04 §3.2 同式）。**分账口径写死：新臂分账分母 = face_new（新臂自身 lit 面），恒等式 |face_new| = Σ7 类终态（Q7 同式在新臂复算）；跨 run 判读只作用于 N520 ∩ face_new 交集，禁止扩到 N520 ∖ face_new（该子集无新臂观测面，单独登记为 out-of-face_new 计数，不进判读）**。

- **D1 恢复率（workload 面直接证据，C2）**：ρ = |{ c ∈ N520∩face_new : terminal(c, grid) ≠ never-enter }| / |N520 ∩ face_new|。
  - **ρ ≥ 0.8 ⇒ workload 面证据成立**（驱动铺满后绝大多数缺席点被点亮 ⇒ 缺席 = workload 未覆盖，C2 获直接证据，候选升级交 judge）；
  - **ρ ≤ 0.2 ⇒ 残留稳定缺席 ⇒ 立 idk-K2c**（覆盖到位仍不进 light ⇒ 缺席不在 workload 面，idk-K2a 的 never-enter 归并方向被否定，另立候选）；
  - **0.2 < ρ < 0.8 ⇒ mixed**：分账 + 空间分布全量落盘，judge 强制复核（不判 PASS）。
- **D2 空间位移（辅助读数，非独立判据）**：新臂 never-enter 集（face_new 内）质心与 N520 质心位移量、以及 N520 三子组（198 框外 / 119 z=188 带 / 203 散点边带）分组恢复率——三组分别出数；z=188 带作先验子组单列不并入 D1 分母（#112 同 design-260920-04 §3.3：直线带结构已 confirmed，防循环论证）。
- **D2' 竞态分账（防 GRACE 压缩误读）**：新臂资格丧失类（init0/precheck-fail/collect-fail/degrade/legacy-*）**必须仍全零或近零（<1%）**——非零 ⇒ dwell 压缩引入新资格丧失源，D1 读数**降权登记**（ρ 的证据效力标注「含压缩竞态混杂」，不改判据、不 VOID，由 judge 定夺）。
- **形态门（#199）**：D1/D2 只在 Q1-Q7+QG1-QG2 全过后计算；按 abi=blocks9/packed/legacy 三形态分列出，禁止跨形态混算单一 ρ（混算形态作 overall 仅登记）。

### 3.3 driver 覆盖率指标（judge S2 交付，分 terminal 类出）

cov(face_new) = |{ c ∈ face_new : min Chebyshev 距离(c, waypoint 集) ≤ 10 }| / |face_new|；并按 terminal(c) 分类各出一份。**门**：cov ≥ 0.95 ⇒ 判据可判；0.90-0.95 ⇒ 判据可判但 S2 读数随判据 json 报告级登记（hold-all 下不应出现，出现即登记异常）；**< 0.90 ⇒ 判据 suspended → exit 5**（数据有效但 workload 判别不可判，禁冒充 PASS）。waypoint 距离 ≤10 即 T6 半径，机械可算。

### 3.4 VOID 非零退出
