## 范围（含明确不做什么）

- 做：C-3 域批 packed 直传（`-Pdomainpacked=1` 门控）+ C-4 bridge 缓冲 thread_local 复用；
  判据预登记先行（criteria-260919-03.md，含 preconditions 字段——v0.22 待办③落地）；
  位等价单测 + 三臂复测（off/on25/onpk）+ worker 裁断 + judge MUST + 知识库落盘。
- 不做：C-1 域共享增量化（G3 未解）、C-2（round4 冻结约束）、GPU 轴（三次否决不重开）、
  内核侧 Scratch/b9 复用（idk-1）、多 seed 外推。

## 任务拆解

- T1 判据预登记 + 时序锚 commit（先于采集）。
- T2 实现：Rust 侧泛化解码 `light_decode_packed` → 帧式域批解码 + 新 JNI 入口；
  Java 侧提交线程 packed 收集 + 任务体拼接 + `packed=` 自证字段；bridge b25/outv thread_local。
- T3 验证：位等价单测 → 复测台（改 DLL_SHA8 + 三臂）→ worker 裁断 → judge → candidate 交用户。

## 预置子角色介入点

- scout：无（机制地图已有 scout-map §2；无「机制未明」面）。
- worker：T3 verdict 裁断（subagent）。
- fan-out：B-主 未满足且 B-C3/B-C4 均未满足 ⇒ 三互斥候选（Java 拼帧残留 / Rust 解码成本 /
  拷贝份额高估）.b1/.b2/.b3 并行；否则不触发。
- judge：MUST ×1（candidate 授予前，三源核对）+ SHOULD ×1（T1 判据落盘后）；
  重大转向（判据读法偏离/fallback 面扩大）触发即停。
- knowledge：结论性落盘 subagent 产出草稿（prompt 带 SUBAGENT-KNOWLEDGE-GUIDE 行），
  主会话只应用验证。

## 风险与回退

- packed 编解码位等价失败 → 域批回 blocks25 现路（门控回退，legacy 兜底分流现成）。
- thread_local 驻留超预期 → 降级显式预分配池。
- 复测不达标 → 失败轮留档换标签（#144-146），不自动回退。
