## 2. 实施面（判据绑定对象，读法写死）

- **C-3（`-Pdomainpacked=1` 门控，Java sysprop `coreswap.light.domainpacked`）**：
  提交线程收集改 packed 帧（复用 wgLightCollectPacked 同构逻辑，9 chunk/帧）；
  任一 chunk packed 收集失败（global 节/帧形态意外/高度不符）→ 该 center 走现役
  blocks9 内联路（`WG_DOMAIN_INLINE` 计数，语义不变）；域任务全帧在位 → 拼接
  meta(9×432)/pal/sto + frameLens → 新 JNI `lightComputeDomainPacked` → Rust 泛化
  解码进 b25（帧 k 覆盖 chunk 基 = (kz+dz9)*5+(kx+dx9)，后帧覆盖重叠 = 现 arraycopy
  序语义）→ 同内核 light_compute_domain。空边缘槽零填 = AIR（现语义不变）。
- **C-4（无条件，无开关）**：jni_bridge 域批路 b25/outv 换 thread_local 复用
  （照 :289-311 先例；每使用全量覆写论证同款）。内核侧 Scratch/b9 复用不在本块
  范围（登记 idk-1，留 C-1/后续块）。
- **自证（#188 形态覆盖）**：onpk 臂 task 行新增 `packed=<n>` 字段（n=packed 帧数）；
  on25/off 臂 task 行**无**该字段 = 负自证；onpk 臂 packed 字段缺席 ⇒ 该臂 VOID。
- WG_LIGHTPHASE 字段名不变（alloc_copyin 语义 = packed 三数组 copyin）；段/母段
  自洽 sanity（#189）在首臂采集后立即核对：alloc_copyin+kernel+copyout+缺口 ≈ 任务
  核算（×9 ±30% 带），不自洽即停手修打点不解读。

## 4. 判定判据（读法写死；解读归 worker/judge）

主读数 = 臂内全部成功 task 的 P50（nativeMs 为端到端主读；LIGHTPHASE 段为分判据）。

| 判据 | 满足 | 未满足 | 灰区 |
|---|---|---|---|
| **B-主（C-3+C-4 组合，端到端）** | nativeMs P50(onpk) ≤ 0.90 × nativeMs P50(off 同轮) | > 0.95 | 0.90–0.95 双值上报交 judge |
| **B-C3（packed 拷入）** | alloc_copyin P50(onpk) ≤ 0.50 × alloc_copyin P50(on25) | > 0.70 | 0.50–0.70 双值上报 |
| **B-C4（缓冲复用）** | nativeMs P50(on25) ≤ 0.97 × nativeMs P50(off)（上界 ~14% 的下限采样，缺口+分配份额部分可观测） | > 1.00 | 0.97–1.00 双值上报 |
| **行为等价门** | ratioP50(off) 与 0.9831 比值 ≥0.95 **且** ratioP50(on25)、ratioP50(onpk) 与同轮 off 比值 ≥0.95 | 任一 < 0.95 ⇒ 立案不解读 | — |
| **位等价门** | `light_compute_domain_bitwise_equivalence` 绿 + 新增 packed-域解码等价单测绿（构建前置） | 红 ⇒ 不采集 | — |

阈值依据（登记，非事后）：B-主 0.90 = 合计上界 ~25%（verdict §4）取 ≥40% 达成率下限；
B-C3 0.50 = 输入降 ~2 个量级（nonAir 32.6% 锚）下保守 ≥2× 拷入下降；B-C4 0.97 =
上界 ~14% 中缺口/缺页份额的可观测部分保守 ≥3%。阈值均为预登记裁决线，不改读数。

**未满足出口**：B-主 未满足且 B-C3/B-C4 均未满足 ⇒ 触发 fan-out 预置（plan §fan-out：
Java 拼帧残留 / Rust 解码成本 / 拷贝份额高估 三互斥候选 .b1/.b2/.b3 并行）；
单分判据未满足 ⇒ 如实报告归因，不强制 fan-out。
