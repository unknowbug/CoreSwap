## 1. 必答一：K2 原叙述如何被修正

原叙述「批几何/分组 run 级非确定」被本数据**在前半句证伪、在后半句换层**：

- **分组/几何层被实证为 run 级恒定**：批数、size 分布、bbox 形状分布两臂完全相同；且比分布更强——**逐 chunk 的批成员集两臂完全一致**（same_group=1518，diff_group=0）。批划分本身是确定性的（由 workload/驱动几何决定，不随调度漂移）。
- **非确定严格定位于「窗口内容」层**：same_group_diff_hash=1518 意味着在成员集、轮廓、填充几何全部恒定的前提下，窗口内容 hash 仍 100% 两臂全异。注意 blk25 是 25×16×16×384 ≈ 4.9×10⁷ int 的 sha256——**100% 全异只需每窗 ≥1 个元素差**，与「大窗口几乎必然含差」相容，不能读作「整窗内容差」。

因此修正后的 K2 叙述应为：**「批分组恒定 + 窗口内容装配 run 级非确定」**——差异源在 blocks9→blocks25 装配所快照到的**底层方块内容或缓冲区状态**，不在批几何/分组/填充轮廓的决策层。

四个指向候选中，经 §2 判别复算后：「零填充轮廓差」（C2）作为独立充分解释**正式排除**（342 个无填充 3×3 批两臂仍全异）；「拼装顺序」（C3）进一步降权（size=1 批全异。⚠️ judge N2：「size=1 批窗口 = 中心 chunk 唯一真实块 + 恒定零填充」系**条件假设**（criteria §0.1 载明 blocks25 由 9 邻 chunk blocks9 拼装，size=1 窗口的实际组成无一手证据），据此展开的「无邻居装配面」推论一并降级，见 §5 推测层）。候选收敛为「**底层方块内容真差**」（C1a）与「**装配时点快照差**」（C1b，含对中心 chunk 自身内容的时点快照），两者机制上可能同源（见 §2 C1 注）。

## 3. 必答三：与 #179 瞬态假说的关系

**若 blk25 窗口快照在世界 tick 继续推进后采集，#179 预测的签名**：快照内容 ≠ 任何终态；跨 run 的差随「快照时刻 − 终态时刻」的时间窗内发生的块变更（feature 越界写、tick 变更）累积；且同一 chunk 在不同 run 的快照落在演化轨迹的不同点（#70 路径依赖）→ hash 几乎必然两臂全异、差异点随时间窗增长。本数据的 100% 全异与此签名**相容**（但如 §2 所述，与 C1a 签名不可分离）。

**absent520 相邻数据点对「世界仍在推进」的支持**：520 chunk 两臂均无写回行（域批未触），但两臂 light.json 均含全部 520 且 **light_equal_both 仅 223/520（57.1% 两臂相异）**——这些「域批未接触」的 chunk 在采集时点 light 值仍 run 级相异，说明写回阶段之后世界状态（光照/块）仍在被 vanilla 增量推进且推进路径 run 级非确定。这正是 #179「探针瞬态读数 ≠ 最终存档状态」与 #204「值收敛 ≠ 过程确定性」的**直接实例**（与 verdict §3.1 region 终态自差 27.3% 同族互证）。它支持「采集时点快照具有时点性」这一前提，从而**间接支持** C1b 类时点机制的可能性；但它观测的是 light 通道，**不直接证明 blocks 通道存在同型瞬态**——blocks25 差的机制归属仍需 §2 的逐元素复算/新采集。

另注：absent520 的带状边缘结构（dist −1:198 / dist 23:120 / 内部每距 ~9 均匀）说明缺席面**不是随机散布**——支持写回面边界定义的结构性成分（可在下一工作块把 judge N8 的「不预设结构 vs 采样」收紧为「呈带状结构、边界定义层候选」，仍不判死）。
