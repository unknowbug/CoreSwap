# B6-3 课题错误台账（260918-06）

## E1：比对器负向测试首轮假阴性（judge S1 / N6）

- **现象**：负向自检注入 `[LIGHT-PATH] path=ghost-path` 后比对器仍输出 `[OK] ⊆ 声明`、rc=0——门禁判据「注入未知值必须 FAIL」首轮不成立，比对器对未知事件值结构性失明。
- **根因（机制）**：比对器把「运行时事件 → 声明键」建模为**白名单别名表**（ALIASES）；未知事件值不命中任何别名 ⇒ 触达键集为空 ⇒ 与声明的差集恒空 ⇒ 恒 PASS。这是「A=B 恒等不证分支生效」（#81 家族）的比对器形态：**校验器的枚举覆盖面本身就是判据的一部分**，值域封闭性未校验。
- **定位**：按门禁纪律做负向测试（判别实验必须验证「自变量真被改变」，#20）时 rc=0，与预期 FAIL 矛盾；读 actual keys=0 定位到「未知值零键」路径。
- **修复**：比对器加值域封闭校验——`path=`/`abi=` 提取的值 ∉ KNOWN_VALUES 枚举 ⇒ 直接产出 `light:event.value:<unknown>:<值>` 键（必不在声明集内 ⇒ UNDECLARED ⇒ FAIL rc=1）；修复后负向 rc=1 / 正向 rc=0 双向复测通过。
- **教训**：**「基于映射的校验器」必须先校验值域封闭性，再做映射判定**——否则校验器对枚举外世界恒绿（「silently-green 门」#163 家族的运行时形态）。任何「事件→键」归约器首条判据 = 未知值必须FAIL。
