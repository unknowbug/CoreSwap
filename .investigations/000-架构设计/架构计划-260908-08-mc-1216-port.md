## 1. 全局视图

- **目标**：在不动 1.20.1 现役能力的前提下，把 Rust worldgen 管线移植到 MC 1.21.6——按 workspace 拆分架构（260905-01）：`worldgen-core\` 共享引擎吸收 1.21.6 的算法差异（版本化处理），新建 `versions\1.21.6\rust\` 薄壳 + 1.21.6 数据集。
- **双重测试目标（用户拍板，本移植的元目标）**：
  - **T1 数据驱动兑现度**：验收 = 数据/代码改动行数比 + 「换版本只换数据+少量代码」是否成立，收尾量化报告。
  - **T2 项目结构乱度**：勘探线 1a′ 项目结构审计——「新增一个版本目录需要碰哪些地方」为乱度指标（理想 = 只建 versions\1.21.6\rust 薄壳 + 数据，其余零改动）；悬空引用/历史路径残骸/文档口径失准单独出清单，不与移植混账。
- **前置未知（Phase 1 勘探解决，不猜）**：
  - 1.20.1 → 1.21.x（→1.21.6）worldgen 机制变更全集（noise/density function/biome/feature/carver/aquifer/surface rule/多噪声桩等版本差异）。
  - Java 1.21.6 参照权威来源（官方 jar + mappings/sources；现役 runtime 权威仅 1.20.1，工作区外路径铁律——新增参照源需用户指定/批准下载通道）。
  - 现有 generated 数据（blocks/light_data/density 等）的重生成通道是否随版本可用。
- **范围排除项**：不动 1.20.1 薄壳与已 confirmed 结论；mod-compat 载体不重开；第三方数据包兼容挂起。
