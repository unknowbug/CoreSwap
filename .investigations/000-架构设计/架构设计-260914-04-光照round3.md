## 1. 全局视图（目标/范围/排除项）

**背景**：光照正确性已闭合（G1 exact 100%）；性能两轮优化后内核累计 3.65×（5.80→1.59ms/chunk），但 e2e 仍净回退 **1.25×**（ON 17.4s vs OFF 13.9s / 2025 chunks，260905-04 口径）。剩余大头 = 内核 fill 查表（943µs，58%）+ Java 侧收集循环残余。项目铁律「最终标准 = 比 Java 强」⇒ 光照不达标不应接管出货（当前默认关，无发布风险）。

**目标（判据先行，预登记）**：
- 主判据：e2e 四臂交替（ON/OFF/ON/OFF，同 seed 删 world，1.20.1）ON/OFF 中位比 **≤ 噪声带**（同配置摆动带按 #103/#119 先实测，预期 ~±5-10%；达标线 = 回退 <1.05×）。
- 行为门：golden 逐位不变（4 用例 FNV，C4 惯例）+ 双采集对拍（新收集路 vs 旧路 4×MATCH，#48 惯例）。
- 进取目标（非本块验收线）：ON ≤ OFF（净反超）。

**范围**：
- 1.20.1 主线（bench/判据历史载体）；内核改动在 `worldgen-core` 共享核，**1.21.6 侧须跑光照 sanity 回归**（golden + 一次 gate ON 冒烟，不跑全 e2e）。
- G3 首载漂移 7× **不在本块**（正确性问题独立立项；但若 round3 触碰 relight 路径须声明）。

**排除项**：GPU 路线（已三次否决 D24/D25/D27 + 光照不立项简记）；光照线程模型重构（单车道家族已由 R3 异步化范式覆盖，光照线程池宽度不在本块）。
