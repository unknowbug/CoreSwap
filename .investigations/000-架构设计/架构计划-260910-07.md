## 1. 全局视图

**目标**：把 `runtime/<ver>/java/` 的 **loom dev 工程（源码 + 构建定义）** 迁到 `versions/<ver>/java/`，让
① 源码重新进入版本管理；② `runtime/` 回归「只放运行环境」的语义；③ 运行环境（世界/日志/mods，698MB+56MB）**原地不动**（通过 loom `runDir` 指回旧路径），零数据搬迁。

**做到的可判定状态**：
1. **D1** 两个版本（1.20.1 / 1.21.6）的 dev 工程位于 `versions/<ver>/java/`，`gradle :build` 与 `gradle :runServer` **均从新路径可跑**。
2. **D2 等价性门（关键）**：新路径构建出的 jar 与旧路径 1.0.28 jar 在 **class/json 条目级 sha256 完全相同**（证明「只搬位置、不改语义」）。
3. **D3** 运行环境未被搬运：`runtime/<ver>/java/run/` 仍原地（server.properties / world / mods 不动），dev run 仍读写该目录。
4. **D4** 源码已入库：`git ls-files versions/<ver>/java/**` 含全部 `src/main/java/**` + `src/main/resources/worldgen-data/**` + 构建定义；`run/`、`build/`、`.gradle/`、`resources/native/` 仍被忽略（`git check-ignore -v` 双向核）。
5. **D5** 活引用面清扫：`.gitignore`、`AGENTS.md:138`、`NEXT_SESSION.md`、项目内 `run_rust_client.ps1`、发布契约模板；
   **历史文档/证据归档（`.investigations/**`、`versions/*/docs/**`、已发热工单）按历史读、不改写**（改了就篡改证据链），
   但新块文档需注明路径变更点。

**明确不做**：不改任何 Java/Rust 语义；不动 worldgen 数据实体（`versions/<ver>/data/**`）；不动 `runtime/` 下的 vanilla-server / forge-* 环境；不重跑 A/B（代码未变，只跑 1 臂做路径回归）。

## 3. 迁移设计

| 项 | 决定（推荐值，待 HOOK-1 确认） | 理由 |
|---|---|---|
| 目标路径 | **`versions/<ver>/java/`** | 与既有 `versions/<ver>/{rust,data,cpp}` 同构（每版本资产并列）；也是历史原位 |
| 运行环境 | **原地留在 `runtime/<ver>/java/run/`**，由 `loom { runs { server { runDir "…/runtime/<ver>/java/run" } client { runDir … } } }` 指回 | 兑现「runtime = 纯环境」；698MB(1.20.1) 世界/mods/配置零搬迁、零风险；驱动脚本 `-CollectRegion` 读的路径不变 |
| 搬什么 | `build.gradle`、`settings.gradle`、`gradle.properties`、`src/`（含 `resources/worldgen-data`）、`content-test/`、`run_rust_client.ps1` | 源码 + 构建定义 + 子工程 |
| 不搬（派生/缓存） | `run/`、`build/`、`.gradle/`（旧副本**原地保留不动**，确认稳定后再清）、`src/main/resources/native/`（忽略） | 可再生 / 体积大 |
| 散件处置 | `MaterialRules.java`/`NoiseChunkGenerator.java`/`VanillaSurfaceRules.java`/`x` → 移到 **`.tmp/legacy-runtime-260910-07/`**（不删，留回滚）；`.log` 随 `*.log` 忽略不动 | 保持新工程根干净；`mc_src_extract` 已有同源副本 |
| `.gitignore` | 保留 `/runtime/`（环境树继续忽略）；新增：`versions/*/java/build/`、`versions/*/java/.gradle/`、`versions/*/java/run/`、`versions/*/java/src/main/resources/native/`；**源码与 worldgen-data 不设任何忽略** | 源码入库、派生不入库；改完 `git check-ignore -v` 双向核（本项目 #24 教训：目录级 prune 会让 `!` 失效） |
| 引用更新 | `AGENTS.md:138`（现役 Java 权威路径）、`NEXT_SESSION.md`、项目内 `run_rust_client.ps1` 的 `$runJava`、发布契约/工单模板（新路径）；**历史归档不改** | AGENTS §八.10 迁移纪律 |
