## T1 判据 B（机制分辨，dump 分段定位；payload = 3×3 邻域 × 24 节）

dump 对拍 run2 vs run3，按 diff 落段分类（[DUMP-KINDS]）：

1. **meta-diff(bits/psz)**：meta 段（含 `{bits,psz}` 对）有差异 → 空节集合翻转（候选 c）和/或位打包形态翻转（候选 b）——看差异对形态：`{0,0}↔{bits,psz>0}` = 空节翻转；`{bits1,psz1}↔{bits2,psz2}` 且 bits 变 = 位宽形态翻转（候选 b）。
2. **pal-only**：meta 恒等、diff 仅落 palette 段 → palette 序不稳定（候选 a）实锤方向。
3. **sto-only**：meta 恒等（bits 恒）、diff 仅落 storage long 流 → 位打包内容重排（候选 b 变体：同 palette 序同位宽但 entry 排布自由度）。
4. **pal+sto**：混合 → palette 序翻转通常连带 storage 重排（a 与 b 非独立时的耦合形态），登记耦合。
5. **identical**：hash 差但 dump 逐字节同 → hash 采集与 dump 采集非同点（工具缺陷），判 **VOID** 回修探针。
6. **missing**：dump 文件缺失 → 臂自证缺口，该 chunk 判 VOID。

**分辨门（B-pass）**：全部 inputDiff23 成员落同一 [DUMP-KINDS] 类（或单一主类 + 已登记例外）→ 机制候选锁定，进入 T2 构造性验证。多类并存且各自 ≥2 例 → 互斥候选 ≥2 存活 → **MUST fan-out**（core.fanout .bN 并行，禁止主会话自推）。
