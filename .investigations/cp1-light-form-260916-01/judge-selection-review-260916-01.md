## 二、交叉质疑

**冲突 1：.b1「G3 机制最直接命中」 vs .b2「唯一全位正解」。**
- 两案 G3 主张共享同一机制假设：**「把 light 执行搬离调用任务线程 ⇒ 改变重算时机分布 ⇒ drift 下降」**。该假设（H1 的可操作形式）目前只有探针②「(ii) UB 排除、(i) 时机形态主导」一条归因证据，未有任何「搬离即改善」的运行时实证。
- .b2 的「全位」优势真实但**付费在 Phase B**（完成门同位）：Phase A 搬离执行位置但完成门不动，对 G3 的作用与 .b1 同类且同样未证。即：**在 G3 作用机制上，Phase A 的 .b2 与 .b1 是同一赌注**；.b2 的额外确定性（完成门同位）要等 Phase B。
- .b1 的判别价值因此更高：它以远低于 .b2 Phase A 的成本，对「搬离执行位置是否足以使 drift <2.5%」给出二值判别——若不达标，.b2 的 Phase B 收益预期同步降级（H1 弱化），fan-out 重开有据。
- **裁决：.b1 的主张更站得住**——不是因为它更可能对，而是因为它把未证假设转成了廉价的判别实验；.b2 的「唯一全位正解」在 H1 实证前是战略判断非证据判断。

**冲突 2：.b1 拒给数值预测 vs .b2 给出「收敛向 vanilla 0.84% 带」。**
- 两者都不违反 #22（均未把预测进判据），但 .b1 的拒给更严格：它指出「需要的时机分布偏移量无独立实测来源」，并设了证伪出口。.b2 的收敛预期多依赖一层假设链（H1 ⇒ 完成门同位 ⇒ 收敛），且其锚点 0.84% 是 vanilla 自身基线（同载体可比性 §9.7 已声明，无口径问题）。
- **裁决：.b1 更稳。** .b2 的表述可接受，但 judge 要求：0.84% 收敛仅作方向叙事，H1 未获独立判别（如 .b1 臂或专项探针）前禁止作为 .b2 Phase B 立项依据。
- 共同依赖的未实测自由参数（#22 面）：两案的 G3 主张均无「搬离后时机分布」实测；两案的 A1 主张均依赖 fill/JNI 占比或重叠度未测值。三案在这一点上是**同等Degraded**，无一例外。

**冲突 3（judge 主动补查）：.b1 声称「等价门逐位、比 #111 噪声锚更强」 vs .b2 等价门走 run 级指纹。**
- 不冲突：.b1 不改算法本体（纯函数域）可用函数级判定；.b2 改为有状态增量（算法语义变），只能 run 级。两者各自选择了与其改动面匹配的最强可用门——判定双方均合规，且这正说明 **.b1 的验证风险显著低于 .b2**（等价门失败可定位性完全不同量级）。

### 各案进入实现前 MUST 补的最小前置项

**.b1（主案，立项即补）**：
1. `light_compute_phased` fill/BFS/JNI 占比实测（f 家族探针，与 .b3 的 f 探针同批）——fill+JNI <30% 则按其自设判别预登记撤回 A1 主张（保留 G3 主张）。
2. 在飞登记表时序定稿：条目移除点（写回完成后）与第三提交方语义（J1-2）；边缘 chunk 只读等待链对 LIGHT→FULL 时序的影响分析并入 R3（J1-1）。
3. mc_src_extract DataVersion 抽查（继承 scout C5-2，.b1 引其行号引证）。
4. Mutex 移除后编译期借用分离复证 + 并发 stress 脚本设计（R5 缓解的落地物）先行于合入。
