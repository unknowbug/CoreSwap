# B6-1 分支 b1：合法旁路 / 已废弃 定性清单

> 辖区声明：本文件只判「**合法旁路（SCOPED-*）**」与「**已废弃（DEPRECATED）**」。
> 「缺陷 / 漏接线」辖区属 **b2**，本文件对疑似项**只标归属建议、不解释**（见「让渡清单」）。
> 与 b2 互斥判据：**源码注释/javadoc 是否显式声明 `-D<name>=` 用法**（是 ⇒ 本分支）；
> 若注释把该名当作「应当由 -P 送达却没送达」，则属 b2。

## 判据定义（本分支采用）

| 定性 | 判据 | 证据形态 |
|---|---|---|
| SCOPED-DIRECT-D | 设计上即直接 `-D` 手传：消费点 javadoc/注释**显式写出 `-D<name>=` 用法**，或无 `-P` 载体但作为该探针的**已文档化子参数** | 源码 file:line 注释文本 |
| SCOPED-ENV | 由环境变量 / 非 JVM 载体 / 宿主工具消费 | 消费点注释 + 载体核对 |
| DEPRECATED | 声明了但**全载体零消费**，且全仓库（含 scripts/.tmp/.investigations/docs）查得使用痕迹 ⇒ 曾用后被弃 | 全载体 grep 结果 |
| UNKNOWN | 本分支无法定性，让渡 | — |

**关键区分（本分支的核心发现）**：`-P` 未映射 ≠ 漏接线（b2），因为存在一整类**「父探针走 `-P`、子参数走 `-D` 手传」的既有设计**——
`-P<probe>` 只负责开门（`-D<probe>.probe=1`），门内的**调参旋钮**（坐标/尺寸/过滤/输出路径）**设计上就靠 `-D` 直传**，
build.gradle 从未为它们设映射行，源码注释以「用法：-D...」形式显式声明。此为**约定而非缺陷**。
