## 本轮修复的缺陷（五段式摘要，全量版待收尾归档）

1. **Java ChunkStatus 包名**：`net.minecraft.server.world` → `net.minecraft.world.chunk`（一手 yarn）。
2. **ChunkProvider.getChunk 签名**：yarn 一手源 = `getChunk(int,int) -> LightSourceView`（2 参非阻塞），任务书 4 参错误（R2 实锤）；强转 Chunk。
3. **邻 chunk 状态判据过严**：要求 isAtLeast(LIGHT)，实际 LIGHT 任务时邻保证到 INITIALIZE_LIGHT（blocks 自 FEATURES 就绪）→ 100% 假回退；放宽 FEATURES。
4. **收集循环缺 x/z 内层循环**：每 chunk 只采 1 列（k=3456≠884736）→ 修三重循环 + 局部 Mutable（禁静态复用，多 worker 并发）。
5. **Rust 域索引 y/z 解包绑定互换**：`dom_unpack` 返回 (x,z,y) 绑成 (x,y,z) → `y+1<WORLD_H` 恒真 → 顶层 i+2304 越界 panic（#[test] 本地复现定位，非实机猜）。
6. **jni 0.22 set_byte_array_region 类型**：`&[i8]` 非 `&[u8]` → u8→i8 数值保持转换。
7. **数据表 state-luminance 缺陷**：dump 用 default state → glow_lichen em=0（实 7）→ G1 残差 vanilla 2-7/rust 0 全部 block 光；sky 完全一致佐证内核传播正确。修法 = ABI per-cell luminance（上）。
