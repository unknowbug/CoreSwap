### 1.3 heightmap 语义差清单（逐点）

1. **取值口径**：Rust = 预构建快照（world_surface=noise 期 `cd.surface_height`，worldgen_handle.rs:565/650；ocean_floor=carver 前逐列扫描，worldgen_handle.rs:828-829），**feature 期间永不更新**；Java `ChunkRegion.getTopY`（ChunkRegion.java L422-425 口径=sampleHeightmap+1）读 proto-chunk 高度图，**Chunk.setBlockStatus 在 feature 期放置方块会 trackUpdate 高度图**（本 chunk 已放结构/树/湖会改变后续树 y）。**两侧更新语义未对拍**（IDK-T2，见 §5 探针 P2）。
2. **类型映射**：trees_plains 用 `OCEAN_FLOOR`（非 _WG）。Rust `contains("OCEAN_FLOOR")` 一律映射到 carver 前 OCEAN_FLOOR_WG 快照（placement.rs:300）；Java 在 FEATURES 阶段 `OCEAN_FLOOR`（非 WG）实际命中的高度图实例（WG 口径 or 随放置更新口径）未一手核验（**IDK-T1**；SurfaceColDumpProbe.java:71-72 可双口径 dump）。
3. **跨 chunk**：Rust 邻 chunk 高度图缺 → 返回 min_y-1 → 拒（placement.rs:304）；Java 读邻 chunk 实况。in_square 使树限本 chunk → 对树无效，对 patch/花有效（登记）。
4. **底部守卫**：Java `k>bottomY` 输出 ↔ Rust `k<=min_y` 拒（placement.rs:308）——等价 ✅。

### 1.4 已知独立偏差（非 b3 但同链路，判读探针结果时必须区分）

- **c-A**（worldgen_handle.rs:999-1018）：`block_at` 邻 chunk 返回 -1（WG_CA_MIN 默认关）→ get_top_position/can_replace 在 chunk 边缘 2 格内把空气读成「阻挡」→ **Rust 树被截/跳，Java 不会**。方向与观察（rust 树多）相反，但会制造 2 抽 vs 全额的消费差、同样能引发 x/z 错位——**是与 b3 竞争的同形机制**。
- birch 全零（v19）：树种类由 weighted_state_provider/树选择抽签决定，heightmap 不参与 → b3 无法直接解释（只能经流错位间接）。

## 2. 量化评估（用 v19/v18 已有数据）

- **反直接形态**：extra 叶成完整树冠贴 rust-only log（d=1..3 主体）、van-only log (0,76,6)(0,73,6)(0,75,6) 为同一 (x,z) 竖柱而 rust 无 → 若仅 y 差，x/z 集合应一致。common=114/1129≈10% → 排除「仅 y 差」。**b3-直接形态 ✗**。
- **部分流一致**：van-only 22 / rust-only 45 log 意味着约 6 棵 log 位置精确相同（28-22=6, 51-45=6）→ 流前缀一致、**中途分叉**——与「种子一致（p-fix 已验）+ 数据依赖分支翻转」的反馈形态相容；分叉点数据输入三候选：**地形块（b3）/ biome（b2）/ 跨 chunk block_at（c-A）**。
- **区域级失衡**：oak_log 仅 +197 而叶 +29,830（28 chunk >500）。若地形差使 java 大量跳树，rust log 应显著更多（每跳 1 棵 java 少 3-5 log）；+7/chunk 级别不支持「整区域地形普遍差」。更符合「少数 chunk 内个别触发点 → 流错位放大」——**支持反馈形态、不支持广域地形差作为主驱动**。
- 叶/log 产率 van 11 vs rust 20：非决定性（截断树/树冠重叠均可造成），不做机制断言。

## 3. 结论

- **b3-直接形态（高度差→仅 y 差）：refuted**（v19 空间签名反证）。
- **b3-反馈形态：plausible（draft）**——机制在两侧语义中均存在（§1.2），且是「p 序已验一致后仍出现中途分叉」所必需的三类数据输入之一；但**无法仅凭静态分析区分 b3 / b2 / c-A**（三者在同一传导点上不可分）。非 sole explanation；判定为**次要放大器候选**，需探针定谳。
- 置信度：candidate 以下，draft；验证分层 = Degraded（纯静态）+ 待主会话 P1-P3。
