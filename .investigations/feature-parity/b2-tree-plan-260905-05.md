**MVP 最小闭包（覆盖 6 签名中的 5）**：

- **L0（前置闸门，非 tree 也必须）**：placement modifier / 谓词补缺——`surface_water_depth_filter`、`block_predicate_filter` 扩展 `would_survive`/`solid`/`replaceable`/`not`/`all_of` 组合谓词、`environment_scan`、`Biome` modifier 实装、`block_at` 世界读取实装（当前恒 None）。没有 L0，树一个都放不下（would_survive 全被静默丢弃 = 链路照常走但位置域错）。
- **L1（tree 核心）**：`tree` configured feature 解析 + TreeFeature 生成：straight_trunk_placer + blob_foliage_placer（覆盖 oak/jungle_tree/birch/spruce 系主力）+ two_layers_feature_size + trunk_vine/leave_vine decorator（vine 签名）。

### 显式排除（不在本方案范围）

- `count_on_every_layer` / nether 植被（overworld 树 MVP 不触及）。
- `heightmap_spread_double`：数据集未出现（见 §0.4）。

```rust
// ⚠️ 未编译验证。示意：ConfiguredFeature 增树/植被载荷 + parse/generate 分支。
#[derive(Clone)]
pub struct ConfiguredFeature {
    pub id: String,
    pub type_name: String,
    pub ore_config: OreFeatureConfig,
    pub disk_config: DiskFeatureConfig,
    pub spring_config: SpringFeatureConfig,
    pub magma_config: UnderwaterMagmaFeatureConfig,
    pub freeze_top: bool,
    // —— b2 新增 ——
    pub tree_config: Option<crate::tree::TreeFeatureConfig>,      // tree 用
    pub selector_config: Option<crate::tree::RandomSelectorConfig>, // random_selector 用
    pub patch_config: Option<crate::tree::RandomPatchConfig>,      // random_patch / flower 用
    pub simple_block_config: Option<crate::tree::SimpleBlockConfig>, // simple_block 用
}

impl ConfiguredFeature {
    pub fn parse(id: &str, root: &JsonValue, blocks: &BlockRegistry) -> ConfiguredFeature {
        let type_name = root.get("type").and_then(|t| t.as_str()).unwrap_or("").to_string();
        let cfg = root.get("config");
        let mut cf = ConfiguredFeature { /* …原字段… */
            tree_config: None, selector_config: None, patch_config: None, simple_block_config: None,
        };
        if type_name.contains("ore") {
            cf.ore_config = OreFeatureConfig::parse(cfg, blocks);
        } else if type_name.ends_with("tree") || type_name == "minecraft:tree" {
            // 注意：type_name.contains("tree") 会误伤 azalea_tree 等——用精确匹配或 ends_with
            cf.tree_config = cfg.and_then(crate::tree::TreeFeatureConfig::parse);
        } else if type_name == "minecraft:random_selector" {
            cf.selector_config = cfg.and_then(|c| crate::tree::RandomSelectorConfig::parse(c));
        } else if type_name == "minecraft:random_patch" || type_name == "minecraft:flower" {
            cf.patch_config = cfg.and_then(crate::tree::RandomPatchConfig::parse);
        } else if type_name == "minecraft:simple_block" {
            cf.simple_block_config = cfg.and_then(crate::tree::SimpleBlockConfig::parse);
        } /* …原 disk/spring/freeze/magma 分支不动… */
        cf
    }
}
```

> 自检点：① 原 `type_name.contains("tree")` 风格不能照抄（contains 命中面过宽）；② 2026-08-10 拍板注释（L50/L257-258）解除时保留一行 supersedes 指向 G2 归因 + 本课题，符合 §15.4 取代链。
