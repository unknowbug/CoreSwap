## 4. 结论（本块新增的可复用判据）

1. **维度行为门三件套**：① 该维有载体行（否则先补载体）② 跨形态 diff=0（证 exec/异步化不改内容）③ 跨 run diff=0（证该维 Rust 输出确定性）。
2. **nether 的 run 级非确定不来自 Rust 填充层**（本载体范围内成立：指纹跨 run 零差）。judge C8 修正：**不得**据此断言「非确定在下游 Java carver/feature/装饰层」——该因果为**未测外推**（本载体只覆盖 `buf`，未覆盖写回路径，亦未与 #21 的 region 级口径做 §9.7 可比性声明）。**未测候选**：Java carver/feature/装饰层、写回路径、存档序列化。
3. **end 维 nz_sum/条数 ≈ 264 非空格/chunk**（32768 格）——末地空岛稀疏度的载体指纹量级，可作后续 end 课题的 sanity 参照。
