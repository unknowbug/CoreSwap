## 1. CPU 基线差异判定
- 27.69 出处 = estopt-perf-260903-11.txt L14-15（pc_e2e 256 chunks、WG_EST_L2=on、**l2-only 臂 + p1fix 之前代码**）。
- 本轮 37.67 = default（l2+shared，defaultflip-260903-13 翻默认）。载体相同；配置臂/代码版/机器状态不同。
- 关键旁证：两轮 min 几乎相同（23.82 vs 24.53）但 median 差 30% → 地板未变、尾部变重 → 符合 H1 shared 臂开销 / H2 机器漂移，不符合均匀变慢。
- **本轮基线采用 37.67（同机同日 default）**；27.69 降历史参照。
- 补对照实验：pc_e2e 跑 `WG_EST_L2=1 WG_EST_SHARED=0`（l2-only）——≈27.69→H1（shared 开销）；≈37→H2（机器漂移）。

## 2. GPU 固定成本未漂移
- 9.85 vs ~10ms/fill（n=8）、1436 vs ~1375ms/fill（n=6144）；两点拟合 t = F + c·n → **F≈8ms/fill，边际 c≈0.233ms/点**。
- 8-chunk 批折算 172 → ~179.5ms/chunk。**n=6144 时 88% 是边际计算——合批红利已吃完**。
- 落盘补注（本轮已加）：retest 头注「1568 角点集」= 8 chunks × 196 点坐标集全量；n=6144 = 每 fill 6144 点（跨 chunk 攒点），n 语义 = 点数/fill，非 chunk 数。

## 3. Amdahl
- density 14.4ms 是 l2 前底座（est L2 砍的 48ms 就在该段里），**l2 口径 density 段真实占比未知 → qpd1_stage_bench 开 WG_EST_L2 重跑段分解**。
- 保守上限 14.4ms：GPU 批 1436ms/8chunk vs 替换目标 115ms → 慢 ~12.5×，e2e 负收益。
- 提醒：gpu-merge-revisit-260903-12.md（candidate）已拍板降级，重议条件 = 目标「超 Java 10×+」（对标 8 线程 ~4.5ms/chunk）——**本课题目标函数须显式对齐**。

## 4. fan-out 候选量级预判
- (a) 合批+异步 readback 只消 ~8ms 固定成本，收益 ~0.6%，天花板极低；
- (b) 全树单 dispatch 是唯一可能改每点成本常数 c 的方案，潜力唯一 ≥1× 但受 Amdahl 封顶；
- (c) 混合 = (b) 的收尾形态，非独立候选。
- **实验优先级**：① qpd1 l2 段分解（定 Amdahl 分母）② CPU 基线对照（定分子）③ n 扫描（若 49152+ 仍 0.23ms/点则 (a) 出局）。
- **一句话**：当前数据不支撑「GPU 批量化 e2e 显著 < CPU」立项前提；先跑①②，按 density 段占比决定继续 fan-out 或援引降级结论。
