# Scout 管线地图 — Vulkan GPU 算子重立项（260903-16）

> 来源：scout subagent（9cea3d86）勘探报告，主会话落盘。状态：**draft（勘探层）**。

## 1. Rust 侧通道（WorldgenRust/src/gpu_ffi.rs，372 行，WG_GPU_* env 门控默认关）

- 动态 LoadLibrary("gpu_ffi.dll")；导出面：`gpu_ffi_create(seed, spvPath)` / `gpu_ffi_create_ex(seed, spvPaths, outPerSample)` / `gpu_ffi_fill(h, coords, n, out)` / `gpu_ffi_destroy` / `gpu_ffi_last_error`（+诊断 gpu_ffi_split_total/per_sample）。
- 双通路：
  - `GpuDensity`（Final，逐块 finalDensity 98304 点/chunk，4096/批，WG_GPU_DENSITY 门控——**性能已判死 25.4s/chunk，仅保通路**）；
  - `GpuChannelDensity`（Channels，X2 v3：1225 角点/chunk × 5 channel 单批 fill，WG_GPU_CHANNELS 门控——**性能课题现行形态**）。
- 进程级 handle 缓存 `GPU_HANDLE: Mutex<Option<(seed, kind, handle)>>`——create ~75s 只付一次；Final 与 Channels 两个独立 engine 实例（各自 75s，「同 engine 双 pipeline」后置未做）。
- dispatch 粒度：`fill_chunk_gpu`/`build_slices_gpu` 每 chunk 1 次 `gpu_ffi_fill`（1225 点 < 4096 单批，split 上传 ~42MB）。
- 同步语义：fill 返回即输出可用（完全同步；pc2 sync-check mismatch=0/6144 数据层证实）。
- 角点→slices 布局：`((iy*gz+iz)*gx+ix)*5+ch`（gx=gz=5, gy=49），Rust 侧 trilerp + compute_final_density combine（gpu_ffi.rs:322-348）。

## 2. C++ 侧（versions/1.20.1/cpp/worldgen/src）

- `gpu_density_engine.h/.cpp`（PIMPL）：`fill()` 全程持 `fillMtx`（I6/P2-4，防驱动 0xC0000005）→ 固定成本链全在锁内：
  1. ensureBuffers（稳态跳过）
  2. **CPU split**：CpuBackend.split 每点 double→int32+float，1225 点 ≈42MB
  3. upload（vkMapMemory+memcpy，host-visible coherent）
  4. channels 形态：**5 次串行 dispatchPipeline**，每次 = 新建 commandPool+commandBuffer+fence + submit + `vkWaitForFences(UINT64_MAX)` 阻塞 + 销毁
  5. 每 pipeline 后各一次 readback（vkMapMemory+memcpy）
- `vulkan_runtime.h`：单 compute queue；dispatch 每次重建 command pool+fence（**无复用、无异步、无 VkPipelineCache**——grep 零匹配；~75-100s create 全是驱动 shader 编译，每次重付）。
- `gpu_ffi.cpp`：C-ABI shim 不加锁（锁在 engine fillMtx + Rust Mutex 双层）。
- spv 管线：Final = 单 final_density.spv；Channels = ch0..4 五个独立 pipeline（**interp 在 GPU shader 内**；v1/v2 单 shader 多输出两撞编译器墙——4MB OOM / root 自旋 >30min，v3 每 channel 独立 spv 才收敛）。

## 4. 369ms 分解既有证据（.investigations/lossless-accel/）

- **369.28ms/chunk**（median，256 chunks，ON vs OFF 76.93）：pc1-e2e-260903-08；预热收益仅 ~20-25% → 非预热伪影。
- **8-chunk 批（6144 点/fill）稳态 172ms/chunk**（pc2-retest + proposal L9）——攒批本身已砍半。
- 固定成本定性：CPU split + upload + 5 通道串行 dispatch+readback（fence 阻塞）× 次数。
- 双线程零并行收益（ratio≈1.0×，Mutex 真串行化；260903-04「0.61×」判测量伪影）。
- 角点 fill 单 chunk **~246ms/chunk**（route2-260903-05 C1 门）——split 上传主导。
- **n 扫描未做**（proposal 开工第一步悬置）。
- 错误台账：lossless-accel/lossless-accel-errors.md（LL10 等）。

## 5. 批量化改造面

- **C++（主改造面）**：vulkan_runtime（commandPool/fence 复用、异步 submit fence 不立即 wait、双/三缓冲 readback N-2、可选 VkPipelineCache、可选 device-local+staging 上传）；gpu_density_engine fill 拆 submit/complete 两相 API（curCap 机制已有可放大）；gpu_ffi.cpp 加 batch/分离入口。
- **Rust**：gpu_ffi.rs 攒批（1225×N 点/批）；异步 readback 需 slice 生命周期跨 fill（ChunkDensity Vec<f64> 值语义 → 改借用/回调/双缓冲队列）；sample_chunk trait per-chunk 签名 → 批量上移 worldgen_handle 或 GpuChannelDensity 内部攒队列延迟 flush。
- **语义红线**：channel 值插值合法（线性进 combine 前）、final 值插值非法。
- **spv 生成器**（build-tooling #12）：.investigations/perf-rework/gen_final_density.py + gen_final_density_channels.py；产物 versions/1.20.1/cpp/worldgen/gpu-assets/；glslc `-O` 挂起 >25min（无 -O 5 秒）；**shader 改动必须 comp/backend.h/spv 同批原子重编 + 已知值哨兵点 (784,160,-408)→-0.458333343 健康检查**。
