## C-β（判据，judged）：干净重载协议下输入通道活性

定义：`inputDiff23` = run2 与 run3 `[LIGHT-BETA]` hash 不同的 chunk 集（分母 = 两 run 共同 chunk 数）；`changed23` = snap run2→run3 光照 changed 集（同 C-1 口径，本块只作对拍面不判 C-1）。

判定分支（全域覆盖，无灰区）：
1. `inputDiff23 = 0` 且 `changed23 = 0` → **QUIET**：干净重载协议下 β 与 F3 均不可检（本载体 n=1 单 seed）；legacy 收集在重载轮输入恒定。
2. `inputDiff23 = 0` 且 `changed23 ≥ 1` → **F3-CHANNEL**：输入恒定而输出变 → output/未重算侧通道 live，β 排除（本轮）。
3. `inputDiff23 ≥ 1` → **β-LIVE**：β 支持度 = |inputDiff23 ∩ changed23| / max(1, |changed23|)；≥ 0.5 → β 主通道实锤；< 0.5 → β live 但非 changed 主导，第四通道 open 转 fan-out。
