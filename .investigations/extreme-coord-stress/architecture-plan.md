# 架构计划 — 极端坐标 FP 微差应力测试（用户已批准）

> Phase 0 产物。目标：在世界边界（±30M）极限坐标下测 FP 微差是否演变为「地形颠覆」；通过则封存「FP 微差」课题（不影响 perf 轨道）。

## 1. 背景与动机（用户拍板链）

- B1 NOISE 微差定案（confirmed，260902-11）：根因 = 密度零面擦边格符号翻转（FP 求值序微差类），孤立单格 air 孔，端到端 99.9992%，域边界 = 单 seed / 单 biome（basalt_deltas）/ 4×4。
- 放大系数定案（confirmed，260902-10）：feature/carver 链路无放大（0.62 < 1），残差在 surface 层闭合。
- 用户判断：微差课题与未来性能优化轨道正交（修复 = 逐位复刻 Java 求值序，高成本零性能收益），不值得常规网格泛化采样；只需在**最坏情况**（世界边界极限坐标，FP 误差最大位）确认不发生「地形颠覆」即可封存。
- 既有支撑：maintainPrecision 折叠边界 ±3.33554432E7 ≈ 33.5M，±30M 贴边界（docs/02）；floorDiv 负坐标为逆向易错点清单第一条（-8248 前科）→ 负极限必测。

## 2. 采样矩阵（2 seed × 2 极限区 = 4 次端到端对比）

| # | seed | 采样区中心（块坐标） | 覆盖 |
|---|---|---|---|
| ① | 正数 seed | (+29,999,000, +29,999,000) | 双正极限 |
| ② | 同① | (−29,999,000, −29,999,000) | 双负极限（floorDiv 前科位） |
| ③ | 负数 seed | (+29,999,000, +29,999,000) | seed 符号 × 正极限 |
| ④ | 同③ | (−29,999,000, −29,999,000) | seed 符号 × 负极限 |

- seed 语义：纯数字串 → signed int64（负号合法）；选具体值时记录并三查（server.properties 备份 / 删 run\world / 导出 header 核对）。
- 每区 4×4 chunk（对齐 B1 口径，chunk 坐标 = 块坐标 >>4 后对齐）；维度 = 主世界 overworld（用户实际游戏所见）；若工具链在 overworld 采集成本异常，回退 basalt_deltas 并声明口径差异（§9.7）。
- 混合符号角（+x,−z 等）：不单独采（floorDiv 差异由轴符号驱动，双负区已覆盖负轴）；4 区结果形态不一致时再补。

## 3. 验收判据（「不颠覆」= 通过）

- 预登记参考线：块一致率 < 95% 视为崩溃信号（**用户要求：数据出来后先报实际一致率给他过目再裁决 PASS/FAIL，95% 仅预登记**）。
- 崩溃信号（任一即 FAIL）：① 块一致率断崖（对照参考线）② 残差区域连片 / 整 chunk 翻转 ③ 表面高度系统性漂移 ④ biome 判定大面积翻转。
- 通过 = 残差仍为孤立格 / 局部小片形态（数量多于 B1 的 13 列是预期内——极限坐标擦边格密度必然升高——**形态不变**即可）。
- 口径声明 §9.7 三要素同行（载体 = 端到端存档对比；覆盖面 = 2 seed × 2 极限区 4×4；可比性 = 与 B1 basalt_deltas 4×4 口径同层但域不同）。

## 4. 预置子角色介入点

- scout：不需要（管线已勘探清楚，B1 定案继承；非「机制未明」大排查）。
- worker：采集执行主会话（收敛型）；若需独立解读且发散 → core.worker subagent。
- **fan-out（预置）**：结果出现「真结构崩溃 vs 探针口径问题」分叉（≥2 互斥候选）→ 强制并行派 worker 各验一个。
- **judge（MUST，预置）**：结论（通过/不通过）出具前审查；封存结论 confirmed 前同样 MUST。
- knowledge（预置）：封存结论 docs 落盘 = subagent 产出草稿（prompt 含读 SUBAGENT-KNOWLEDGE-GUIDE.md），主会话应用。

## 5. 风险与回退

- 极限坐标附近 vanilla 预生成/探针工具若有未踩过的坑（int 溢出 / 远距 chunk 加载）→ 先 sanity check（块数 TOTAL、chunk 范围、header 五要素），异常即停先查参照。
- 若 4 区一致率形态分裂（如负极限崩、正极限不崩）→ 按分叉处理（fan-out 或直接定位），不平均化结论。
- 全 FAIL → 不封存，课题升级回用户重新裁决（可能意味着真实结构 bug）。
