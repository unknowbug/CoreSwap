## 4. 结论变化（量级判定，非比例折算）

1. **映射非单调**（分母倍 1.004-2.362、% 倍 1.20-2.67）⇒ **禁止按比例折算旧读数**；E5 追记的「不可固定比例折算」在 1.21.6 载体上确认。
2. **「R3 差异 ≤ 历史代理基线 0.0150%」的上界论证失效**：同口径下历史基线 = **0.0180%**，而 R3 跨实现读数 **0.0192-0.0198%** 高于基线 **0.0012-0.0018pp**（旧口径下该组读数全部 ≤ 基线，是**口径产物**）。
3. **同配置 run-to-run 基线（新）**：sync **0.0133%** / async **0.0169%**；跨形态 **0.0173/0.0177%**。跨形态相对 sync 自比高 **0.0040-0.0044pp**，相对 async 自比仅高 **0.0004-0.0008pp** ⇒ 「形态相关分量」仍在，但**与 async 自比的 run 级摆动不可分**（每形态仍只 1 对读数）。
4. **nether 门仍 PASS**：跨形态 0.2978% ≤ 同形态噪声 0.3759% ✅（旧口径 0.1219% ≤ 0.1406% 同向）；接管基线 0.2703% 亦 ≤ 噪声。**限定（judge B-C9，旧 judge C1/C7/FIN-C6 明令须随结论走）**：该噪声为 **async 代理**（该维**无 sync run-to-run 对**，每形态仅 1 对读数）⇒ **单对点估计、检验力低**；PASS 是「同量级筛选门」，不是「接管已验证」。
5. **end 三对不变**（7 / 0 / 0）——E5 只影响分母，不影响该维 diff 计数。
6. **旧读法对 nether/overworld 的系统性失真**（sections/chunk 11.5→24.0、6.8→16.0）说明旧读数**不是「略偏低」而是结构级失真**；所有引用旧 `%` 的结论 MUST 复算后重述。
