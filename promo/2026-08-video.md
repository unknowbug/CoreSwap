# CoreSwap 项目介绍（简版，可作 README/视频文案附件）

## CoreSwap 是什么

Minecraft Java 版性能核心的 C++ 化复刻。把世界生成（密度函数/含水层/矿脉/表面规则）用 C++ 重写，经 JNI 桥回游戏，**逐位一致 + 性能碾压**。

## 核心数据

- **100% 逐位一致（NOISE+SURFACE 阶段）**：验证 seed 下 TOTAL/nonAir 均 100.0000%，地形（山脉/海洋/洞穴/地表）与 vanilla 一个方块不差；矿物/装饰等 FEATURES 层暂由原版生成
- **性能**：vanilla ~60ms/chunk → CoreSwap 批量并行 ~3ms/chunk（**10-20×**）
- **纯算法优化**：FlatCache/Cache2D/spline 缓存等全部无损（不靠近似）

## 技术架构

```
Minecraft (Java, Fabric)
   └─ mixin 拦截 populateNoise/buildSurface
        └─ CppBridge（批量攒批 16 chunk）
             └─ JNI → worldgen.dll（C++）
                  ├─ DensityFunction 树（逐位对齐 Java）
                  ├─ AquiferSampler（含水层）
                  ├─ OreVeinSampler（矿脉）
                  └─ VanillaSurfaceRules（表面规则）
```

- **批量并行**：攒批 16 chunk 一次 JNI 调用，C++ 侧自适应 `min(核数, 任务数)`
- **零中间分配**：native 层紧凑数据布局（flat 数组，无装箱/无临时对象）——GC 压力自然减小
- **MSVC 构建**、JDK17 固定（Fabric Loader 0.15.11 要求）

## 与 Sodium/Iris 的关系

| | Sodium/Iris | CoreSwap |
|---|---|---|
| 层 | 渲染（帧率） | 生成（探索加载） |
| 解决 | 原地帧率低、光影 | 跑图时 chunk 加载卡 |
| 冲突 | 无 | 无（互补） |

**实测组合**：4060 笔记本 + BSL + 32 视距全程不卡。
