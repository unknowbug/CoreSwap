## 1. 结论

**1.20.1 的 R3 异步化成立（candidate）**：overworld / nether / end 三分支的 `populateNoise` 接管段由
「在传入车道 executor 上同步执行」改为「在 `Util.getMainWorkerExecutor()` 上异步执行」，把重活移出 worldgen 单车道。
三面证据齐备：**形态直证**（`inflight max` 1 → 23）、**量级**（Chunky 口径 **5.97-6.00×**；相对 vanilla **1.32-1.35×** 更快，
而同步形态慢 **4.44-4.54×**）、**内容门**（同 chunk 原生输出指纹 **4140/4140 逐 chunk 相同**）。
Rust/C++ **零改动**（执行体与 260910-05 同源 dll）。

**限定**：nether/end 只做**接管生效 sanity**（未做行为门）；region 逐块对拍受 1.20.1 run 级非确定限制（§4.2，检验力低）；
指纹门只覆盖 overworld（4140/4225 processed = 98.0%，§4.4）；vivo 未测（交用户实机，观察级）。

## 4. 行为门（四层；噪声无关的那一层是决定性证据）

### 4.1 第一层（决定性）：原生输出**逐 chunk 指纹** —— 4140/4140 相同

仪器 `CppBridge.wgBufHash`（FNV-1a 64，对 `fillBlocks` 写回 buffer 逐 int 位置敏感混入），`-Pmixlog=1` 打印
`[WG-CONTENT] chunk(x,z) hash=<hex> nz=<n>`。对比 `osS-r2`（sync）与 `oaS-r2`（async）：

| 指标 | 结果 |
|---|---|
| sync / async chunk 数 | **4140 / 4140** |
| 交集 | **4140**（两侧差集 0 / 0） |
| **指纹不一致 chunk** | **0** |
| 臂内「同 chunk 多份互异指纹」 | sync **0** / async **0** |
| `nz`（非空气格数）不一致 | **0**（区间 15569-42692） |

judge **独立**（自写解析器，未复用 `cmp_content_hash.py`）全量 join 复核：交集 4140、差集 0、hash 不一致 0、dup 0、nz 0 处不同；
并核 `intercepted` 行数 4140、`[CppBridge] DIAG` 行 0（无 chunk 因早退路径被跳过）⇒ 与本节一致。

⇒ 换形态**不改变**任何 chunk 的原生输出（本出货语义下 Rust 侧 = per-chunk 纯函数；与 260910-05 对 `pending_cross_writes` 的结论一致）。
**边界（J11）**：指纹取在 `writeChunk` **之前** ⇒ 覆盖「原生计算」，**不覆盖写回/并发路径**（见 §7.5 开放项 b3）。
