# X2 通道对拍 bA：Rust macrolize ch0 是否丢 y 依赖（260903-05）

- **状态**: draft（静态结构分析，Degraded——无运行时探针，证据为生成代码结构 + JSON 结构对照）
- **输入**: seed=8576294172403134396 chunk(0,0) 对拍异常（route2-260903-05.md：Rust ch0 在同 (x,z) 列 y=8/16 同值 -1.386253、y=200/208 同值 -1.139378；GPU ch0 随 y 变化；ch1-4 全绿）
- **任务**: 判定「Rust ch0 丢 y 依赖」假设真伪

## 1. JSON 侧结构（versions/1.20.1/data/worldgen/data/minecraft/worldgen/noise_settings/overworld.json）

- `noise_router.final_density` 全树 DFS **只有 1 个 `interpolated`**（即 ch0），路径 `fd.argument1.argument.argument2`：
  `interpolated( blend_density( add(0.117, mul(ycg(-64→-40: 0→1), add(-0.117, add(-0.078, mul(ycg(240→256: 1→0), add(0.078, range_choice(sloped_cheese, …)))))))))`
- 内联树自身只有 **2 个 y_clamped_gradient**（上面两个 blend fade）；其余 y 依赖全部经**命名引用**进入：
  - `overworld/sloped_cheese` = add( 4*quarter_negative((depth + jaggedness*half_negative(jagged y_scale=0)) * factor), base_3d_noise )
  - `overworld/depth` 含 **ycg(-64→320: 1.5→-1.5)**（真 y 依赖）
  - `overworld/caves/entrances` 含 **ycg(-10→30: 0.3→0)** + 3 个 **cache_once**（精确 xyz）
  - caves 分支（range_choice out_of_range）：cave_layer(y_scale=8)、cave_cheese(0.667)、spaghetti_3d/2d、pillar 等真 3D 噪声
- 结论：**Java/GPU 侧 ch0 inner 存在大量真 y 依赖节点**——与 GPU eval_df_base_0 随 y 变化的观测一致。

## 2. Rust macrolize_into 本身（WorldgenRust/src/density.rs:690-767）

- `macrolize_into` 对 `Interpolated` 仅做「inner arg 原样 Arc 进 channels + 换 ReadChannel」，其余节点逐 arm 递归 clone；
- `YClampedGradient` arm（density.rs:743）完整保留 from_y/to_y/from_value/to_value；`Noise` 保留 y_scale；`ShiftedNoise`/`RangeChoice`/`WeirdScaled` 均递归。
- **判定：macrolize/通道化本身是忠实的，不丢 y 依赖。**（ch0-ch4 的划分也只影响采样调度，不改树语义。）

## 3. 真正的丢点：transpiler 生成物（WorldgenRust/src/generated/vanilla_density_functions.rs:163 `fill_cell_corner_densities_final_density` out[0]）

对 35,522 字符的 ch0 行做括号精确配平 + 闭包嵌套分析（脚本 .tmp/ch0_analyze.py）：

- 仅 **3 个 y_clamped_gradient 在任何 cache 闭包之外、用真 y**：col 65（blend fade1 -64..-40）、col 175（fade2 240..256）、col 304（depth 梯度 -64..320 的**第一份内联副本**，即 range_choice input 处）。
- 从 col 462 起整个余下子树嵌在 `transpiler_cache_2d(1000032, __fcq_x, __fcq_z, || { let x=__fcq_x; **let y = 0.0f64**; … })`（及后续 1000042/1000041/1000063/… 等同形 2d 缓存）的闭包内，配平验证 col 10346 / 20372 / 22023 / 34048 全部位于这些 y=0 闭包之内：
  - **depth 梯度副本 2、3**（col 10346、22023）：y 被 shadow 成 0.0 → 恒值
  - **entrances 梯度 -10..30**（col 20497、32193）：同上
  - **slide 梯度 -64..320: 8→-40**（col 34048）：同上
  - **cave_layer / cave_cheese / spaghetti_3d / spaghetti_2d / pillar 全部 3D 噪声**（col 20372-35399，含 y*8、y*0.667 等真 y_scale）：同上——在 y=0 处采样一次并按列复用
- 缓存语义（density.rs:335 `transpiler_cache_2d`）：key = (x,z) only，注释自述「y 无关（xz-only）」；命中即整列复用同一值。

### 机制判定

transpiler 对 JSON **命名引用子树**（sloped_cheese / depth / factor / jaggedness / entrances / caves 分支）做内联去重时，把它们包进按 (x,z) 缓存、闭包内 `y=0.0` 的 cache_2d——这只对真 2D 子树（spline 的 erosion/continentalness/ridge 采样，y*0.0）合法；对其中**嵌带的 y_clamped_gradient 与 3D 噪声**是错的：y 依赖被压平成 y=0 处的常量并整列缓存。

这与对拍观测完全自洽：blend fade 在 y∈[-40,240] 为常 1，depth 唯一真 y 副本（col 304）所在项对角点值的贡献被 factor 乘子/分支路径掩盖（该列 factor≈0 或走缓存副本），其余全部列内恒定 → **y=8 与 y=16、y=200 与 y=208 角点值逐位相同**。ch1-4（生成行 164-167，noodle 通道）直接用真 y 采样，故全绿。

## 4. 结论

- **「Rust ch0 丢 y 依赖」＝ 真（candidate，静态结构证据）**。丢失点不在 `macrolize_into`（忠实），而在 **build.rs transpiler 生成 `fill_cell_corner_densities_final_density` 时对命名引用子树的 2d 缓存包装**：将 y 依赖节点（depth/entrances/slide 梯度 + caves 全部 3D 噪声）关进 y=0 的 (x,z) 列缓存。
- **GPU 侧无可疑点**：GPU ch0 随 y 变化与 JSON 结构一致；差异归因 Rust 侧。
- 修复方向提示（未验证）：transpiler 引用内联时仅可对「证明 y 无关」的子树（全部噪声 y_scale=0 且无 ycg）施 cache_2d；含 ycg/3D noise 的引用必须按 (x,y,z) 失效或退出缓存。
