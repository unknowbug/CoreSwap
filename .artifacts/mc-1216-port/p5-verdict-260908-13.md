## Java 侧语义（1.21.6 实测，一手源码）

参照源：`versions/1.21.6/data/mc_src_extract/net/minecraft/world/chunk/`（yarn 源码 extract）。

- `ChunkStatus.java`：1.21.6 本体**只有 previous 链**（EMPTY→STRUCTURE_STARTS→…→FULL），**无** 1.20.x 的 `range`/邻居半径字段——邻居依赖语义已迁出本类。
- 迁移落点 = **`ChunkGenerationStep.java` + `GenerationDependencies.java` + `ChunkGenerationSteps.java`**：
  - 每状态一个 `ChunkGenerationStep(targetStatus, directDependencies, accumulatedDependencies, blockStateWriteRadius, task)`；
  - `Builder.dependsOn(status, level)` 声明直接依赖（level = 邻居半径），`accumulateDependencies()` 逐步累积；`GenerationDependencies.getAdditionalLevel(status)` 供调度层换算 ticket 附加层级。
  - GENERATION 链要点（`ChunkGenerationSteps.java`）：STRUCTURE_REFERENCES dependsOn(STRUCTURE_STARTS, **8**)；BIOMES dependsOn(STRUCTURE_STARTS, 8)；NOISE dependsOn(STRUCTURE_STARTS, 8) + dependsOn(BIOMES, 1) + blockStateWriteRadius(…)；SURFACE 同构；CARVERS dependsOn(STRUCTURE_STARTS, 8) + writeRadius 0；FEATURES dependsOn(STRUCTURE_STARTS, 8) + dependsOn(CARVERS, 1)；LIGHT dependsOn(INITIALIZE_LIGHT, 1)；SPAWN dependsOn(BIOMES, 1)。
